# Reflexión sobre el uso de IA

En este documento se incluirá una reflexión personal sobre el uso de herramientas de inteligencia artificial en el desarrollo del proyecto.

Se analizarán los beneficios, las limitaciones encontradas y cómo estas herramientas pueden integrarse en el flujo de trabajo de un desarrollador. 

# Reflexión final

Durante esta práctica he utilizado varias herramientas de inteligencia artificial como ChatGPT, Cursor y también he investigado GitHub Copilot para comparar cómo ayudan durante el desarrollo de una aplicación.

La verdad es que al principio no estaba muy acostumbrado a trabajar con este tipo de herramientas, pero poco a poco fui entendiendo cómo podían ayudarme tanto para programar como para entender mejor el código.

## Beneficios del uso de IA

Lo que más útil me pareció fue la rapidez. Muchas veces podía pedir explicaciones sobre errores o funciones y obtener respuestas bastante claras en pocos segundos.

También me ayudó bastante para:

- detectar errores en funciones
- refactorizar código
- añadir comentarios y documentación
- entender conceptos de JavaScript
- mejorar algunas funciones del proyecto

Con Cursor, por ejemplo, fue más fácil modificar funciones directamente dentro del proyecto y entender cómo estaban conectadas entre sí.

## Riesgos y limitaciones

Aunque la IA ayuda mucho, también vi que no siempre genera el mejor código posible. Algunas veces las respuestas eran demasiado complejas o añadían cosas innecesarias.

Por eso creo que es importante revisar siempre el código antes de aceptarlo y no copiar todo directamente sin entenderlo.

También pienso que si una persona depende demasiado de la IA puede acabar aprendiendo menos, porque muchas veces la herramienta hace casi todo automáticamente.

## Comparación entre Cursor y GitHub Copilot

En mi caso, Cursor me pareció más útil para trabajar sobre un proyecto completo porque tiene chat integrado, análisis del código y herramientas para modificar varias partes del proyecto más fácilmente.

GitHub Copilot me dio la sensación de estar más centrado en autocompletar código rápidamente mientras escribes.

Creo que Cursor es más cómodo para aprender y entender proyectos grandes, mientras que Copilot es más útil para escribir código rápido.

## Conclusión

En general, esta práctica me ayudó a entender mejor cómo se puede usar la inteligencia artificial dentro del desarrollo web.

Pienso que estas herramientas pueden ahorrar mucho tiempo y ayudar bastante, pero siempre es importante revisar lo que generan y entender el código antes de utilizarlo en un proyecto real.
