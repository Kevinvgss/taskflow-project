# Backend API - Herramientas y tecnologías

## Axios

Axios es una librería para realizar peticiones HTTP desde JavaScript. Permite hacer solicitudes GET, POST, PUT o DELETE de forma sencilla y manejar respuestas asíncronas.

Se utiliza porque:
- simplifica las peticiones HTTP
- maneja errores fácilmente
- convierte respuestas automáticamente a JSON

En este proyecto se utilizó fetch, que es la alternativa nativa de JavaScript.

---

## Postman

Postman es una herramienta para probar APIs REST.

Permite:
- enviar peticiones HTTP
- probar endpoints
- visualizar respuestas
- comprobar errores y códigos de estado

Es muy útil durante el desarrollo backend.

---

## Sentry

Sentry es una plataforma de monitoreo de errores.

Se utiliza para:
- detectar errores en producción
- registrar excepciones
- analizar fallos del sistema
- mejorar depuración

Muchas aplicaciones profesionales lo usan para detectar bugs automáticamente.

---

## Swagger

Swagger es una herramienta para documentar APIs REST.

Permite:
- documentar endpoints
- probar APIs desde navegador
- generar documentación interactiva
- facilitar el trabajo entre frontend y backend

Es muy utilizado en proyectos profesionales y microservicios.
